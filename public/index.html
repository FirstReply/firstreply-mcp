Setup

Up and running in three steps.

  1. 01

    Add FirstReply to your assistant

    The server address in Claude or ChatGPT, one command in Claude Code, or a short config in Claude Desktop, Cursor or VS Code.

  2. 02

    Sign in

    Allow the connection with your FirstReply account; the assistant then works with your permissions. Where a sign-in is not possible, use an API key from Organization Settings.

  3. 03

    Ask in plain language

    Check the inbox, draft a reply or schedule a post. Every change shows up in the web app.

Run this in your terminal, then type /mcp in Claude Code and sign in with your FirstReply account:

claude mcp add --transport http firstreply https://mcp.firstreply.ai/

In Claude, open Settings, Connectors and add a custom connector with this address, then sign in with your FirstReply account:

https://mcp.firstreply.ai/

In ChatGPT, add a connector in the settings with this address, then sign in with your FirstReply account:

https://mcp.firstreply.ai/

Add this to claude_desktop_config.json, then restart Claude:

{ "mcpServers": { "firstreply": { "command": "npx", "args": ["-y", "@firstreply/mcp"], "env": { "FIRSTREPLY_API_TOKEN": "fr_your_api_key" } } } }

Add this to ~/.cursor/mcp.json:

{ "mcpServers": { "firstreply": { "url": "https://mcp.firstreply.ai/", "headers": { "Authorization": "Bearer fr_your_api_key" } } } }

Add this to .vscode/mcp.json:

{ "servers": { "firstreply": { "type": "http", "url": "https://mcp.firstreply.ai/", "headers": { "Authorization": "Bearer fr_your_api_key" } } } }
